# 작업 4-2 — HYPER HEXAGON 60fps 회피 파트 랜덤 연결·플레이

**기준:** `rebuild-step-4-1-hyper-hexagon-20261116` 브랜치, 4-1 커밋 `41a1989c8a426639eea841be6ae07df5cbd84395` 이후. 이번 작업은 4번 HYPER HEXAGON만 대상으로 하며, 5번 HYPER HEXAGONER 구현을 시작하지 않는다.

## 원본 영상과 구간

- `1594.mp4` = 업로드 `1595(3).mp4` (SHA-256 동일), 실제 HYPER 구간 382.990–472.623초. HYPER 게임 시간 약 0–93.368초, 5,379개/60fps 기록.
- `1557(20261116-003454).mp4` = 업로드 `1596(3).mp4` (SHA-256 동일), 실제 HYPER 구간 303.320–398.603초. HYPER 게임 시간 약 0–99.253초, 5,718개/60fps 기록.
- 게임 시간 환산은 HUD 대비 25/24배 추정치다. 다른 단계·메뉴·편집 컷은 이 HYPER 데이터에 포함하지 않았다.

## 파트 구분

| 원본 | 0–60초 | 60초 이후 | 합계 |
| --- | ---: | ---: | ---: |
| `1594.mp4` | 15 | 8 | 23 |
| `1557(20261116-003454).mp4` | 15 | 10 | 25 |
| **합계** | **30** | **18** | **48** |

소스 전체 기록에서 도형 전환 시점과 중앙 근처 벽 밀도를 참고해 연속 회피 동작의 경계를 잡았다. 원본 프레임을 건너뛰지 않고 [0, 영상 끝] 전체에 걸쳐 경계를 이어 붙였다. 60초는 기록상 **프레임 3456**으로, 같은 프레임열의 동일 벽 객체를 계속 이어서 사용한다.

## 구현

- `data/hyper-hexagon-4-2-bank.json`: 두 원본의 순차 48파트 경계 및 60초 전/후 구분.
- `hyper-hexagon-parts.js`: 60fps 영상별 회피 파트 재생, 48방향·0.12초 간격 이동 가능 경로 검사, 출입구 방향 정렬, 현재 벽 유지, 60초의 분할 없는 이어쓰기, 랜덤 시드 및 두 소스 균형 선택. 화면 바깥 새 벽 발생은 **외곽 컨투어 도달 대리 지표**로 검사한다. 원본 엔진의 정확한 spawn 명령 복원은 아니다.
- 원본에서 바로 연속되는 파트에서는 같은 벽 ID를 유지한다. 비연속 파트 연결은 이전 파트의 진행 중인 벽을 최대 1.55초 원래 영상의 후속 프레임에서 추적하고, 원래 배우 추적이 끊어질 경우 매우 짧게 추정 이동을 적용한다.
- 충돌 계산은 HYPER 중심 작은 점을 기준으로 하며 240Hz 엔진 보간 단계에서 동일 벽 ID의 두 연속 60fps 외곽선을 보간해 빠른 얇은 벽의 통과 누락을 줄인다.
- 원래 4-1 팔레트는 OpenCV BGR 값을 RGB로 오인해 벽·배경 색이 역전되는 오류가 있었다. **두 원본을 rgb24로 직접 재추출**한 20fps 9채널 RGB 팔레트로 4번 맵만 교체했다. 예: 1594 영상의 게임 59.9초 원본 청록색 배경·벽을 적갈색이 아니라 청록색 계열로 다시 표현한다.
- 플레이 HUD: 영상의 POINT/LINE/... 랭크, HYPER MODE, 우측 0.01초 타이머, 60초 LEVEL UP, 기록 갱신/사망 화면 디자인을 참조해 4번에만 적용. 카메라는 영상의 프레임별 회전·줌을 유지하고, 소폭 픽셀 떨림·사망 확대를 적용한다.
- `?trace=1595`, `?trace=1596`으로 랜덤이 아닌 원본 1회 재생으로 비교할 수 있다. 일반 시작은 두 소스에서 파트를 랜덤 선택한다.
- 1–3번 맵, 기존 메인 화면, 7번 맵 삭제 상태는 유지한다. `main`은 변경하지 않는다.

## 확인 범위와 정직한 한계

- Node: 원본 데이터 5,379/5,718 프레임 로딩, 60초 원본 배우 ID 연속성, 파트 48개 전부 연결, 벽 회피 영역과 충돌 영역 분리, 고속 좁은 벽의 중간 위치 보간, 60초 전후 두 소스 선택, 다양한 랜덤 시드 160초 이상 시뮬레이션. 참고 시드 1/8/23/59/1234/441/7/98/18/6666에서 확인된 첫 모의 결과는 비검증 폴백 0, 160초 미만 조기 종료 0이며, 외곽 배우 도달 지표의 최대 공백 0.9초였다.
- 브라우저: 메뉴에서 4번 HYPER 진입, 두 시작 소스, 파트 전환·60초 전후·충돌/사망·재시작·메뉴 복귀. `?trace` 원본 모드와 기존 1–3번 맵 회귀도 별도 실행한다.
- **필수 한계:** 색상 추출·외곽선 벡터화·캠 추정은 원본 엔진의 벽 생성 파라미터를 역복원한 것이 아니다. 완전한 픽셀 일치와 실제 사람이 160초 이상 회피 가능한 모든 연속 입력 경로는 증명되지 않았다. 랜덤 세션의 '안전성'은 48방향/0.12초 격자 추정이며, 화면에 나타난 컨투어의 새 등장 시간은 원본 게임이 보이지 않는 화면 바깥에서 호출한 벽 생성 명령 시간이 아니다.
- 플레이 속도 8.5rad/s, 픽셀 떨림의 크기, HUD 일부 타이밍/폰트, 음성/음악 박자와 원본 사망 연출의 완전한 일치는 추가 직접 영상 비교가 필요하다.
