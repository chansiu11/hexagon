## 검증 범위와 주의

단위 테스트는 두 원본 전체를 디코딩하여 48파트 원본 연속성, 게임시간 60초 경계, 벽 충돌/비충돌과 복수의 난수 시드로 165초 관전자 재생을 확인한다. Chromium은 실제 게임 시작·모드·화면 전환·랜덤/원본 경로·사망 및 재시작을 검증한다.

**유의:** 이 코드는 녹화 영상의 60fps 실루엣을 다시 재생하는 방식이다. 원작 내부 벽 생성 명령·원래 게임 엔진의 정확한 속도/카메라/음향 이벤트를 역추출한 것이 아니므로 픽셀 단위 동일·실제 사람이 모든 시드에서 60초 생존 가능·모든 벽 생성 간격 1초 이내를 확정하지 않는다. 연결 순간의 화면색/투명도는 원본 편집과 다를 수 있다. 관전자 시뮬레이션의 통로 유무는 동적 조작의 생존 보증이 아니다. 후속 단계 5는 포함하지 않는다.
