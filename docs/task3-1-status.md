## 확인된 저장소 상태

- 이 기반 브랜치는 구형 수십 개의 플레이 스크립트가 있는 `main`/다른 실험 브랜치와 다르게 새 `engine.js`, `replay.js`, `parts.js`, `stages/hexagon.js`, `stages/hexagoner.js` 기반이다.
- `stages/hexagonest.js`와 HEXAGONEST 녹화 데이터는 존재하지 않는다. 따라서 지워야 할 *이 브랜치의* 구형 HEXAGONEST 구현도 없다.
- 세 번째 맵을 완성된 것처럼 등록하지 않는다. 실제 영상 벽 데이터 없이 새 레벨을 실행하게 하면 빈 맵/즉사/가짜 장애물이 발생하기 때문이다.
- 이미 구현된 첫째/둘째 맵과 메뉴/7번 삭제 상태를 유지한다.

## 이 브랜치에서 구현한 것

- `hexagonest-chronology.js`를 추가했다. 같은 영상 안의 프레임/벽 ID가 게임시간 60초 경계를 통과할 때 끊기거나 두 번 생성됐는지 확인하는 순서·타이밍 감사 도구다.
- 1595 및 1596 두 개의 *서로 다른* 추출 데이터만 입력받도록 하며 시작 오프셋, 60초 뒤 존재 여부, 매 프레임 벽 폴리곤과 개별 ID, 등장시각, 색상은 아닌 카메라 줌 범위, 도형 변화, 등장 간격을 검사한다.
- `test/hexagonest-chronology.test.cjs`에 두 동영상 구분/60초 지속/누락 데이터 거부/잘못된 벽 ID 거부에 대한 합성 데이터 회귀 테스트를 추가했다.
- index.html에서는 검사 도구만 로드한다. 3-1의 미추출 영상 데이터를 가짜 값으로 등록하지 않는다.
